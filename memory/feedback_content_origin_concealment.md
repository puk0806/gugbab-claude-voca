# 콘텐츠 출처 답습 흔적 제거

**Why**: 2026-05-13~14 작업 중 사용자가 직접 지적. 보고서 §4.6.5d에 *Unit 1~15* / *DAY 001~100* / *책 단원명("쿨하게 말하기", "간단하게 내 느낌 표현하기")* 같은 표현이 그대로 들어가 *특정 책의 목차를 답습한 것처럼* 보였고 저작권 관점에서 위험. 사용자 발언: "이런식으로 표현하면 어떤 책을 긁어온거 같잖아. 자연스럽게 조사해서 가져온것처럼 다른것과 동화되게 바꿔야지."

**How to apply**: 콘텐츠 큐레이션 / 리서치 보고서 / docs 어디에서든 외부 책·강좌·블로그 *영감*을 활용할 때:

## 절대 박지 말 것 (책 답습 흔적)

- Unit 번호 (Unit 1·Unit 2·…)
- DAY 번호 (DAY 001·DAY 100·…)
- 책 단원 제목 그대로 ("쿨하게 말하기", "딱 한 단어로 시작하기", "뜬금없이 동사로 시작하는 표현" 등)
- 책·강사·강좌·인물 이름 (어떤 형태로든)
- 한국어 해석을 *책 표현 그대로* 옮기기

## 항상 사용할 패턴

- *언어학적·기능적 분류*로 재구성:
  - "epistemic modality" / "reduced future" / "modal hedging"
  - "formulaic sequence" / "discourse marker" / "hedging expression"
  - "interrogative tag" / "cohortative" / "politeness formulae"
- 공식 학술·정부 자료만 출처:
  - NGSL-Spoken (Browne·Culligan·Phillips) / Cambridge Empower / Cambridge EVP
  - Oxford 3000 by CEFR / Spoken BNC2014 (Lancaster CASS) / COCA Spoken
  - British Council LearnEnglish / US State Department Everyday Conversations
- *corpus linguistics 톤*으로 보고서 작성 — Wray 2002 / Schmitt 2010 같은 연구 인용 가능

## 검증 체크리스트 (콘텐츠 작업 종료 전)

- [ ] grep으로 `Unit \|DAY 0\|쿨하게\|간단하게\|뜬금없이\|딱 한 단어` 등 *책 답습 키워드* 검색해 0건 확인
- [ ] 보고서 분류 표가 *기능군·언어학 카테고리*인지 (책 단원 제목 X)
